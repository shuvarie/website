> This website is a stub (mostly) generated by AI and built with Jekyll. A rewrite will be commenced in the near future.

An agentic AI pair-programmer that lives in your **terminal**. Shuvarie reads
your code, edits files, runs tools and keeps a forkable history of every
decision — all under explicit, granular permissions you control.

<div class="features">
  <div class="feature">
    <h3>🔌 Bring your own model</h3>
    <p>OpenAI-compatible, Anthropic, Ollama and more — configured in one
    <code>connections.kdl</code>, switchable on the fly with <code>/model</code>.
    A peak/off-peak countdown follows whichever model bills by time of day.</p>
  </div>
  <div class="feature">
    <h3>📜 Codemode</h3>
    <p>One tool that runs a Rhai script, and the script calls the others:
    dependent calls become one round trip and intermediate results never
    reach the context. On by default, with a <code>/codemode</code> roster
    switch.</p>
  </div>
  <div class="feature">
    <h3>🌲 Sessions &amp; forking</h3>
    <p>Every session is a tree. Inspect it with <code>/tree</code>, roll back
    with <code>/undo</code>, replay, and export or import sessions as JSON.
    A failed or interrupted turn resumes where it stopped.</p>
  </div>
  <div class="feature">
    <h3>🧩 Skills</h3>
    <p>Reusable prompts and procedures stored as markdown, invoked straight
    from the prompt as <code>/skill:&lt;name&gt;</code>.</p>
  </div>
  <div class="feature">
    <h3>🎨 Scenes &amp; themes</h3>
    <p>Built-in <strong>Advisor</strong>, <strong>Reviewer</strong> and
    <strong>Orchestrator</strong> scenes, plus five theme families. Drop in
    <code>scene.d</code> and <code>themes.d</code> files, switch live with
    <code>/scene</code>.</p>
  </div>
  <div class="feature">
    <h3>📎 Attachments</h3>
    <p>Type <code>@path</code> to attach documents (pdf, docx, xlsx, epub,
    …) or images; the model reads them through <code>read_file</code>.</p>
  </div>
  <div class="feature">
    <h3>🛡️ Permissions &amp; trust</h3>
    <p>A workspace trust prompt on first run, plus a granular allow/deny
    <code>permissions</code> section — optionally backed by decision
    models. The agent never acts unbound.</p>
  </div>
  <div class="feature">
    <h3>⌨️ Keyboard-first</h3>
    <p>Every action has a keybinding, and <code>Ctrl+M</code> puts every
    command one keystroke away.</p>
  </div>
  <div class="feature">
    <h3>🖥️ Headless mode</h3>
    <p><code>shuvarie run "…"</code> drives the agent without the TUI,
    streaming the reply to stdout and the tool log to stderr — the same
    config, permissions and sessions.</p>
  </div>
</div>

## Try it

```sh
# with Nix (flakes enabled)
nix run github:shuvarie/shuvarie            # try it
nix profile install github:shuvarie/shuvarie  # keep it

# or with a Rust toolchain, from a checkout
cargo install --path .
```
